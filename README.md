# NIIGATA LIFE ATLAS / 新潟生活観測所

「移住する前に、暮らしを観測する。」を掲げ、新潟への移住を、エリア・移動・冬・ハザード・住まい・食・支援制度から考える非公式リサーチサイトです。行政や不動産会社の公式サイトではなく、公開情報と現地確認へ進むための判断材料を整理します。

## ページ構成

- `/` — 新潟移住の論点、エリアノート、暮らしのリアリティ、一次情報へのリンク
- `/map` — マンション・酒蔵・飲食店を同じ座標系で探索するD3.js生活地点マップ
- `/food` — 都会の食好きに向けた、新潟市の料理人・店・味を追うレストラン研究
- `/housing` — 公開マンション情報の観測データベース、D3.jsによる可視化、個人用比較ツール
- `/relocation` — 移住前の考慮点、2026年度の支援制度、契約・転入前後の確認順序

## 主な機能

- 公開情報を「観測日・出典つきスナップショット」として収録
- D3.jsと地理院タイルで、地点のズーム・移動・カテゴリ切替・検索・詳細連動
- マンション、酒蔵、飲食店を共通の地点データ形式へ変換
- 料理人の経歴や店の思想を、公開インタビュー・公式情報とともに紹介
- エリアと利用シーンで絞り込めるレストラン研究インデックス
- 実食メモと、公開情報から編集部が読み解いた味の見立てを明確に区別
- D3.jsで「駅徒歩×㎡単価」「広さ×価格」を切り替える散布図
- 駅前・駅南・万代・関屋による動的フィルター
- 候補マンションの追加・編集・削除・比較対象の切り替え
- 価格、㎡単価、固定費、駅距離などの動的な比較表
- 評価軸の重みを変えられる参考スコア
- 金利、返済期間、頭金、駐車場代を反映した月額試算
- ブラウザへの自動保存（`localStorage`）
- JSONによるバックアップと復元
- 新潟駅南口西地区の都市再生特別地区に関する判断材料

## 開発

必要環境は Node.js 22.13 以上です。

```bash
npm ci
npm run dev
```

本番用のビルドと検証は次のコマンドで実行できます。

```bash
npm run build
```

## データについて

地図へ地点を追加するときは、該当カテゴリのデータファイルを1件更新します。

- マンション：`app/data/public-listings.ts`
- 飲食店：`app/data/restaurants.ts`
- 酒蔵：`app/data/breweries.ts`

各レコードに名称、住所、緯度経度、出典URL、観測日を持たせると、`app/data/places.ts` が地図用の共通形式へ変換します。カテゴリ固有の項目は変換時に地図の詳細欄へ割り当てます。座標は住所代表点として扱い、現地入口の厳密な位置を保証するものではありません。

レストラン研究はランキングや広告企画ではありません。店・料理人の公式情報、公開インタビュー、受賞記事などを参照し、出典と観測日を付けて紹介しています。実食していない店の味については、公開された料理方針や第三者記事からの編集上の見立てであることを明記しています。営業状況、価格、コース内容は変わるため、来店前に各店の公式情報を確認してください。

公開データベースは在庫一覧ではなく、SUUMO等の公開ページを観測した時点の記録です。掲載終了や同一建物の別住戸を含みます。売出し状況、価格、管理費、修繕積立金、駐車場条件などは変動するため、購入前に最新の販売図面、重要事項説明書、管理規約、長期修繕計画、総会議事録を確認してください。

入力した候補は利用中のブラウザ内に保存され、サーバーには送信されません。別端末へ移す場合は画面下部のJSON書き出し・読み込みを利用します。
